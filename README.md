# بسته استقرار VexVPN روی Railway

## فایل‌ها
- `bot.py`: کد اصلی
- `database.py` و `inventory.py`: ذخیره‌سازی SQLite و مخزن
- `report_system.py`: گزارش‌گیری
- `config.py`: خواندن تنظیمات از متغیرهای محیطی Railway

## راه‌اندازی
1. این ZIP را استخراج کن و همه فایل‌ها را در ریشه یک مخزن GitHub قرار بده.
2. مخزن را در Railway به‌عنوان پروژه Deploy کن.
3. در Railway از بخش Variables متغیرهای زیر را اضافه کن:
   - `BOT_TOKEN`: توکن تازه ربات از BotFather
   - `ADMIN_IDS`: شناسه عددی ادمین؛ برای چند ادمین با کاما جدا کن
   - `CARD_NUMBER`: شماره کارت (در صورت استفاده از پرداخت کارت‌به‌کارت)
   - `CARD_HOLDER`: نام صاحب کارت
   - `BRAND_NAME`: نام برند، مثلاً VexVPN
   - `SUPPORT_USERNAME`: آیدی پشتیبانی بدون @
   - `DB_PATH`: `/data/bot_data.sqlite3` (اگر Volume به مسیر `/data` متصل کرده‌ای)
4. برای ماندگاری اطلاعات، در Railway یک Volume بساز و آن را روی `/data` mount کن. بدون Volume، فایل SQLite ممکن است پس از redeploy یا جابه‌جایی سرویس از بین برود.
5. Deploy را انجام بده و از بخش Deployments لاگ‌ها را بررسی کن.

## مهم
- توکن ربات را داخل GitHub یا ZIP قرار نده؛ فقط در Railway Variables تنظیمش کن.
- اگر توکن قبلاً جایی منتشر شده، قبل از Deploy در BotFather آن را revoke کن و توکن تازه بساز.
- اگر دیتابیس فعلی و اطلاعات انبار را می‌خواهی منتقل کنی، فایل `bot_data.sqlite3` را جداگانه و امن به Volume منتقل کن؛ این ZIP عمداً دیتابیس و فایل‌های حاوی اطلاعات محرمانه را ندارد.
- این پروژه از polling استفاده می‌کند؛ فقط یک replica از ربات اجرا کن تا چند نمونه هم‌زمان پیام‌ها را پردازش نکنند.
